# 通用自动化脚本

保存可跨业务复用的小工具，例如批量重命名、文件归档、文本清洗、格式转换和文档批处理。仅服务招标或微信业务的脚本归入对应业务目录。

## 当前状态与建议结构

目前仅有本说明，尚未迁入脚本。

| 路径 | 用途 |
| --- | --- |
| files/ | 重命名、归档、文件清单工具 |
| text/ | 文本清洗及格式转换 |
| documents/ | 文档和图片批处理入口 |
| examples/ | 脱敏输入与预期输出 |
| tests/ | 必要的行为验证 |

目录在实际迁入时按需创建；每个独立工具附同名说明或子目录 README。

## 单个脚本 README 模板

复制以下清单并填写真实值：

- 名称及用途：待填写。
- 入口文件与工作目录：待填写。
- 操作系统、运行时版本及安装步骤：待填写。
- 输入格式、参数、示例文件：待填写。
- 执行命令及预期输出：待验证后填写。
- 是否改写、覆盖、移动或删除文件：待说明。
- 预览模式及备份方式：涉及文件变更时填写。
- 常见错误、退出状态及恢复方法：待填写。
- 调用方及兼容性约定：待填写。

## 迁入与验收

先迁低依赖、用途明确的工具，用小批量脱敏副本验证结果。会变更文件的工具先核对预览和回退能力，再处理正式文件。依赖清单随代码迁入，移除个人机器绝对路径；运行输出和日志留本地。

验收须有一组输入、明确的执行步骤和可检查的输出，确认重复执行行为符合说明后，再供业务模块调用。
