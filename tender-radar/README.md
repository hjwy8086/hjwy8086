# 恒基招标雷达

维护招标公告抓取、关键词筛选、去重、日报生成和项目跟踪的代码与规则。

## 当前状态

本目录目前仅有说明文档，尚未迁入可执行代码；以下是迁入约定，不代表功能已实现。现有本地 Codex 招标雷达继续作为唯一运行入口，迁入文档和代码不代表启用新的定时任务。

## 建议结构

| 路径 | 用途 |
| --- | --- |
| src/ | 抓取、解析、筛选、去重及日报生成 |
| config/ | 可公开的地区、关键词和来源配置；凭证使用环境变量 |
| templates/ | 日报及项目跟踪空白模板 |
| examples/ | 脱敏公告、去重输入和预期输出 |
| tests/ | 解析、筛选、重复公告处理的验证 |
| docs/ | 来源说明、运行步骤、调度与故障处理 |

## 迁入步骤

1. 记录原项目位置、运行命令、依赖、调度方式及输出位置，备份现有版本。
2. 先迁筛选规则、来源清单和空白日报模板，再迁抓取及去重代码。
3. 用脱敏样例验证同一公告重复输入不会重复输出，原有去重字段和状态可以兼容。
4. 实际 seen.md、历史归档和在办投标状态留在本地受控位置，保留完整备份；仓库仅放格式说明和脱敏样例。
5. 手动对比原流程与迁入版本的结果，再决定切换；切换时停用旧入口并保留回退路径，避免重复抓取和播报。
