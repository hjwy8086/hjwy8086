# 公司 AI 工作说明与模板

保存可以公开的公司 AI 使用规范、业务流程说明、品牌口径和空白模板。

## 当前状态与建议结构

目前仅有本说明，以下子目录按实际资料逐步建立。

| 路径 | 用途 |
| --- | --- |
| public-profile/ | 已核实的公开公司简介与品牌口径 |
| workflows/ | 接单、生产、配送、投标等脱敏流程说明 |
| ai-guidelines/ | AI 使用、事实核验和人工审核规范 |
| templates/ | 空白表单、文案及项目说明模板 |

## 单份文档模板

- 文档名称、目的与适用范围：待填写。
- 状态：草案／试行／已批准，选择实际状态。
- 负责人、审核人、版本及生效日期：待确认。
- 输入、步骤、输出和交接要求：待填写。
- 异常情况、处理人及升级路径：待填写。
- 依据来源与最近核实日期：待填写。
- 变更记录：记录版本、日期与修改内容。

## 迁入与验收

先迁空白模板、公开品牌资料和 AI 使用规则，再迁脱敏业务流程。核对信息来源、有效版本及可公开范围，确认没有把讨论中的建议写成已生效制度。

本公开仓库不放身份证、银行卡、财务凭证、客户名单、报价底价、合同原件、诉讼证据、资质证照原件、人员资料或投标内部资料。此类文件保留在受控存储或另行授权的私有仓库；本目录只记录不含敏感信息的资料分类和使用规则。

## 维护信息模板

迁入时逐项填写，未知项保留“待确认”，不要把示例写成已实现功能。

- 负责人：待确认
- 来源位置／原项目：待确认
- 最近验证日期：待确认
- 当前版本／提交：待确认
- 依赖及版本：待确认
- 输入与输出位置：待确认
- 执行命令（含工作目录）：待确认
- 验证方法及预期结果：待确认
- 故障处理与回退方法：待确认
