## 使用原则

1. 本仓库公开，只提交可公开代码、脱敏示例和空白模板；客户隐私、身份证、财务数据、合同原件及内部投标资料留在受控位置。
2. 不把 API Key、密码、Token、Cookie 或登录状态写进仓库；凭证用环境变量，本地资料放仓库外或已忽略的 private/ 等目录。提交前检查暂存内容，.gitignore 不能代替检查。
3. 重要修改保留版本记录和回退方法，新增代码附真实运行说明。
4. Mac mini 作为主要执行环境，MacBook 和 ChatGPT/Codex 用于查看、分析和协作。
5. 每个模块明确区分已实现功能与待确认事项，不编造命令、依赖或运行结果。

## 建议迁入顺序

| 阶段 | 迁入内容 | 原因与完成标准 |
| --- | --- | --- |
| 0：盘点与备份 | 原项目路径、版本、依赖、入口、定时任务、数据位置及可公开范围 | 先有迁移清单和可恢复备份，确认哪些资料不能进入公开仓库 |
| 1：company-docs | 空白模板、公开品牌口径、AI 使用规范及脱敏流程 | 为后续筛选规则和运营文案提供一致依据，确认草案／生效状态 |
| 2：scripts | 低依赖通用工具及其说明 | 用脱敏副本验证输入、输出和回退，供业务模块复用 |
