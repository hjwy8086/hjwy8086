# 恒基 AI 工作仓库

这是贵州恒基广告图文有限公司用于沉淀 Codex 自动化、运营脚本、项目说明和 AI 工作规范的 GitHub 仓库。

## 计划用途

- `tender-radar/`：招标雷达相关脚本、规则和说明
- `wechat-automation/`：朋友圈、视频号、公众号等内容自动化
- `scripts/`：通用自动化脚本
- `company-docs/`：不含敏感信息的公司 AI 工作说明与模板

## 使用原则

1. 不上传客户隐私、身份证、财务数据、合同原件等敏感资料。
2. 不把 API Key、密码、Token、密钥直接写进仓库。
3. 重要自动化修改先保留版本记录，必要时可回退。
4. Mac mini 作为主要执行环境，MacBook 和 ChatGPT/Codex 用于查看、分析和协作。
